# 🔱 Royal Bio Data Maker (Dual View PDF Engine)

Ek ultra-attractive aur modern **Biodata Maker** jo marriage aur professional profiles ke liye banaya gaya hai. Isme ek powerful feature (twist) hai: **Admin View** vs **User View**!

---

## 🌟 Key Features & The "Twist"

### 1. 👑 Admin View (Full Details)
- Isme aapke dwara bhari gayi **saari details (100%)** show hoti hain.
- Saath hi ye bhi pata chalta hai ki kaun-kaun si details user ke liye hidden (Admin Only) hain taaki aap double check kar sakein.
- **Admin PDF Download & Print**: Is button se poori complete details wali PDF print/download hoti hai aapke system me.

### 2. 👥 User View (Selective Details)
- Isme **sirf aur sirf wahi details** show hoti hain jo aapne User PDF ke liye choose ki hain!
- **Zero Empty Holes / Blank Spaces**: Agar koi detail ya pura section hide kiya gaya hai, to layout dynamically adjust ho jata hai aur koi awkward khali jagah nahi aati.
- **User PDF Download & Print**: Is button se clean public PDF banti hai jise aap rishtedaro ya prospective proposals ko bina kisi private information ke bhej sakte hain.

### 3. 🎯 Har Field ke Samne Instant Toggle Switch
- Har ek field (Income, Address, Mobile Number, Time of Birth, Blood Group, Maternal Gotra, etc.) ke samne **"In User PDF"** ka toggle button hai.
- Ek click me aap kisi bhi detail ko Public ya Private bana sakte hain.
- **Quick Privacy Presets**:
  - 🛡️ **Hide Sensitive**: Ek click me Income, exact address, personal mobile, aur time of birth ko hide kar deta hai.
  - 👁️ **Show Everything**: Saari details user view me dikhata hai.
  - 🔒 **Basic Matrimonial Only**: Sirf basic bio aur family background dikhata hai.

### 4. 🎨 4 Shahi & Attractive Themes
- 👑 **Royal Crimson & Gold**: Traditional Vedic & Rajasthani deep maroon aur shahi gold border ke saath.
- 🌿 **Regal Emerald & Gold**: Shahi emerald green aur gold finish.
- 🌌 **Sapphire Navy & Champagne**: Modern royal navy aur champagne gold.
- 🌸 **Pastel Rose & Velvet Gold**: Contemporary soft rose aur gold elegance.

### 5. 🔱 Auspicious Symbols & Headers
- Lord Ganesha (श्री गणेशाय नमः), Om (ॐ), Vedic Swastika (卐), Mangal Kalash, Khanda, Crescent & Star, Royal Floral Mandala ya None.

### 6. 📷 Profile Photo Support & Custom Fields
- Photo upload karein, agar User view me photo nahi dikhani to photo ko bhi User PDF se hide kar sakte hain!
- Kisi bhi section me nayi **Custom Field** add kar sakte hain (jaise Diet, Hobbies, Expectations, Property, Visa status, etc.)!

## 🚀 How to Run (Kaise Chalayein)

Aap do aasan tareeko se isko chala sakte hain:

### Option 1: 1-Click Batch File (Sabse Aasan)
- Sirf `Start_BioData_Maker.bat` file par **double-click** karein.
- Ye automatic browser me open ho jayega!

### Option 2: Terminal / NPM Command
```bash
npm start
```
Browser me `http://localhost:3000` automatically open ho jayega.

### Option 3: Direct Browser Open (Offline)
- Direct `index.html` par double click karke bhi aap kisi bhi browser me chala sakte hain bina kisi server ke!

---

## 🖨️ PDF Generation & Print
- **Download Admin PDF**: High-quality A4 vector PDF directly download hoti hai.
- **Download User PDF**: Sirf select kiye gaye options wali clean PDF download hoti hai.
- **Print System Dialog**: Direct printer par print karne ke liye `Print User` ya `Print Admin` click karein.
